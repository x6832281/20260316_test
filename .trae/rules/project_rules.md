# 项目永久记忆 / Project Rules

## 产品定位（核心方向，长期有效）

**一个让全球用户用 AI 和游戏方式进入中国古代历史的互动平台。**

英文表述：
**An interactive platform that lets global users enter ancient Chinese history through AI and gamification.**

## 方向说明

- 不是“讲历史”的内容站，而是让用户“玩历史、问历史、测历史、对话历史、对比文明”。
- 把中国历史从“内容”变成“体验”。
- 面向国内与海外双市场，中英双语优先。
- 内容是中国古代历史的，产品形态是全球化的。

## 核心模块方向

1. 历史人物 AI 对话
2. 历史人格测试
3. 朝代 / 事件闯关
4. 文明对比（中国 vs 世界其他古文明）

## 技术与产品约束

- 前端：Vite 静态站点起步，保持轻量。
- 国际化：所有面向用户文案需预留中英双语结构。
- 可传播性优先：测试、对话、对比类功能优先开发。
- 商业化路径：流量变现 → 订阅变现 → 内容/IP 变现。

## 开发原则

- 任何新功能都应服务于“AI + 游戏化 + 中国古代历史 + 全球化”这一核心定位。
- 不做纯百科、纯博客、纯文章聚合类内容。
- 优先做可分享、可留存、可扩展的产品形态。
