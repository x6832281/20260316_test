本报是怎么印出来的

采集流水线 · 仓库结构 · 运行方式

一个每日热门内容采集流水线：以关键词为入口，抓取各平台当天最热内容的评论区数据， 加上 GitHub Trending 全站热门项目。评论与弹幕经由官方 Web 接口采集（MediaCrawler 框架 + 自研脚本）， like_count 为接口原值，非估算。

采集目标排序依据数据来源登录要求
小红书 · 经典高赞评论评论点赞数（历史爆款笔记）/api/sns/web/v2/comment/page扫码一次，长期复用
小红书 · 今日最新评论评论点赞数（仅近 24 小时发布）/api/sns/web/v2/comment/page同上
B站 · 高赞评论评论点赞数（游客可见热评 Top3）/x/v2/reply?sort=2免登录
B站 · 热门弹幕弹幕发送频次（聚合去噪后）comment.bilibili.com/{cid}.xml免登录
GitHub · 热门项目今日新增 Star 数（Trending）github.com/trending 页面解析免登录

由 daily_run.py 统一编排，每天 09:00 定时触发，自动跑完五轮采集后落盘到 daily/<日期>/ 目录，再自动更新本页并推送上线。浏览器进程异常时自动清理重启，登录态失效时提示人工介入而非卡死。

仓库结构

daily_run.py # 每日编排（五轮采集入口）
mc_comment_filter.py # 小红书评论筛选 → TXT
bili_danmaku.py # B站弹幕采集 + 去噪
bili_comments.py # B站高赞评论采集
github_trending.py # GitHub Trending 热门项目
sync_to_github.py # 日报 → 自动更新本页并推送
MediaCrawler/ # 采集底座（需另行 clone）
data/ # 每日 TXT 日报（按日期）
index.html # 本页面（数据呈现）

运行命令

完整流水线（首次运行会弹出浏览器要求扫码登录小红书，之后免扫码）：

# 安装依赖
pip install -r requirements.txt

# 一键采集（约 15-30 分钟）
py -3.12 daily_run.py --keywords "手机"

每天 09:00（北京时间）定时执行：采集完成后自动检查当日五份 TXT 是否产出并更新本页。登录态失效时会提示手动扫码，而非卡死等待。
