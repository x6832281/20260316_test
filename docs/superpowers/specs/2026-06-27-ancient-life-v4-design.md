# 设计文档:你的古代人生 v4 — 双层留存架构

> An AI + gamified platform that lets global users *live* inside real ancient Chinese history.
> Version: v4 · 定稿于 2026-06-27
> Supersedes v3 (`docs/PRODUCT_PLAN.md`) by adding a daily collective-recall layer on top of the v3 roguelite sunk-cost core.

---

## 0. 一句话定位

> **每天,全人类一起被丢进中国历史的同一个岔路口。你做一次不可逆的抉择,AI 推演你的命运,写进只属于你的人生卷轴。活完这一段,换一个朝代重来——但那个懂你的 AI 知己,记得你活过的每一世。**

English: `Every day, the world relives one fork in Chinese history. You choose, irreversibly. AI unfolds your fate and writes it into a life-scroll only you own. Live one life, then another dynasty — but your AI confidant remembers every life you've lived.`

---

## 1. 背景与动机:为什么从 v3 升级到 v4

v3 (`docs/PRODUCT_PLAN.md`) 押注单一留存引擎:**沉没成本 + 不可逆多周目**。它扎实但有三个隐性天花板:

1. **慢热**:沉没成本需 2-3 周沉淀,前 7 天无硬召回理由,冷启动期流失。
2. **重**:每段人生 = AI 推演 + 日记 + 卷轴,单次会话重、token 成本高,难做 DAU 量级。
3. **孤独**:纯单人,私密体验难病毒传播,缺"别人都在等明天"的集体悬念。

v4 的核心动作:**在 v3 的沉没成本之上,叠加一个"全球每日同题"召回层**,补上日留存短板,并制造天然的分享/比较钩子。深度层保留 v3 全部机制,不推翻已验证的思考。

---

## 2. 留存脊柱:三层叠加

整个产品的核心。三层共用**一套历史事件库 + 一个 AI 推演核心**。

| 层 | 留存引擎 | 单次时长 | 频率 | 解决什么 |
|---|---|---|---|---|
| **召回层** | 全球每日同题 + 集体悬念 + 命运卡分享 | 1-3 min | 每天 | 日留存 / 前 7 天硬召回 / 获客 |
| **深度层** | 私人分身 + 不可逆决策 + AI 知己 + 人生卷轴 | 5-15 min | 每天可深入 | 月留存 / 沉没成本 |
| **重生层** | 分身老死 → 新朝代新出身,知己延续记忆 | 一次性 | 数周一次 | 长留存 / 累积深度 |

**一题两用**:同一道每日题,浅层玩家只看"全球怎么选",深层玩家把它写进自己的私人人生。内容成本不翻倍,一人能扛。

---

## 3. 三层机制详述

### 3.1 召回层 — 每日全球岔路口

- **每天一道题**:基于真实纪年(如 755-11 范阳,安禄山起兵),24h 限时,全球同题。
- **三选一不可逆**:① 南逃 ② 守洛阳祖宅 ③ 投军平叛。选完即锁。
- **AI 推演命运卡**:30-90 天命运推演 → 一张可分享卡片(你的结局 + 一句史实注脚),中英双语。
- **次日揭晓群体结果**:"全球 41% 南逃,仅 6% 活到 60 岁;守洛阳者 73% 殁于战乱。" → 制造"明天再来看"的悬念。
- **软损失**:不选不罚,但这天的历史过去了,你和世界错过同一段(合法 FOMO)。
- **轻量身份**:无需注册即可玩(本地存档),想保留命运卡历史才注册。

### 3.2 深度层 — 你的私人古代人生

- **分身绑定真实纪年**:出生年/地/出身绑定真实朝代(首发唐朝天宝年间)。
- **每日岔路写进私人人生**:召回层那道题,在你的私人人生里就是"你今天遇到的事"。知己参谋一句,你决策,AI 推演 3-6 月命运,写进**分身日记**。
- **AI 知己(5 archetype)**:隐士(道)/ 太史(儒)/ 词客(文)/ 谋臣(智)/ 禅师(佛)。长期记忆,遇事给建议,决策权在用户。
- **不可逆**:决策不撤回,后果由 AI 推演落地。
- **人生卷轴**:每段人生沉淀成永久资产(时间线 + 关键抉择 + 日记 + 关系)。

### 3.3 重生层 — 千年累积(Phase 2,MVP 不做)

- 分身老死 → 开新人生(换朝代/出身)。
- **知己延续**:灵魂连续,记忆不断("上世你在黄州,这世我再来陪你")。
- 卷轴越积越厚 → 第 3 个月比第 1 个月更舍不得断。
- MVP 不做,但**数据结构现在就预留**(知己记忆、卷轴列表)。

## 4. 内容引擎:复用架构

"一人扛得住"的关键。

```
历史事件库 (JSON: 朝代/年/月/事件/真实人物/两难选项/史实注脚)
        │
        ├── 召回层: 全球同题 → 群体聚合(只计数) → 命运卡
        │
        └── 深度层: 注入私人人生 → 知己参谋 → AI 推演 → 写卷轴
```

- **事件库做一次,复用 forever**(安史之乱、王安石变法、崖山之变…)。
- AI 在事件库的**强约束**下生成:"必须符合 X 年背景,不得虚构重大史实。"
- 召回层只跑"群体统计 + 命运卡模板",深度层才跑"个性化推演 + 日记"。**浅层玩家不消耗重 AI。**

---

## 5. AI 用法与成本纪律

| 用途 | 频率 | 成本控制 |
|---|---|---|
| 每日题生成 | 每天 1 道,可批处理 | 事件库约束 + 模板,低成本 |
| 命运卡推演(召回层) | 每用户每天 1 次 | 模板化 + 缓存,可控 |
| 私人命运推演(深度层) | 仅深度玩家触发 | 才跑重 AI,浅层不触发 |
| 知己对话 | 按需,限频 | 长记忆 + 限频 |
| 群体聚合 | 每天 1 次批处理 | 纯统计,无 AI |

**原则**:浅层(召回层)几乎不烧 token,深度层才烧——而深度玩家是未来付费人群,成本由订阅覆盖。

## 6. MVP 范围(4 周)

### In
1. **召回层闭环**:每日全球同题 + 三选一 + 命运卡 + 次日群体揭晓 + 分享
2. **深度层最小闭环**:分身生成(唐朝天宝) + 每日题写进私人人生 + 知己一句话参谋 + AI 推演写日记 + 中英双语

### Out(MVP 不做,数据结构预留)
重生层、长安城可视化、每日一卦、节气节日、知己语音、人生卷轴 PDF 导出、订阅支付

### 生死指标
- 召回层 **D7 留存**
- 命运卡**分享率**

不达标则深度层再花功夫也白搭,需先验证召回层。

## 7. 架构与技术

- **前端**:Vite + Vue 3 + TypeScript + Tailwind CSS + vue-i18n(中英双语,CLAUDE.md 已锁)
- **存储**:LocalStorage / IndexedDB(私人人生本地化)
- **群体聚合后端(唯一后端)**:Cloudflare Workers + KV。只存"每日各选项计数",匿名 device id,无 UGC、无实时同步、无账号体系。免费额度内,一人能扛。
- **AI**:OpenAI / Claude API,初期;后期可换国内模型降本。
- **部署**:Vercel / Cloudflare Pages(静态)+ Workers(聚合)。
- **隐私**:日记默认私密,命运卡分享可选匿名。

> **对 v3 "纯本地无后端" 的偏离**:群体聚合需要一个计数后端。但它是只写计数、无 UGC、无账号的最小后端。这是"全球集体悬念"引擎的必要代价。

## 8. 面向全球 + 获客

- **全球同题天然国际化**:"what would you do in history" 是 r/HistoryWhatIf(200 万)、TikTok 已验证病毒题材。
- **命运卡**为核心病毒载体:AI 生成"你的古代结局 + 史实注脚",中英双语,可发小红书 / TikTok / Reddit。
- **知己 archetype 跨文化通用**:sage / mentor 原型,不堆砌"中国城审美"。
- **文案双语预留**:中文古雅,英文 literary(不用 thou/thee 俗套古英语)。
- **冷启动钩子(Phase)**:"你的前世是哪个朝代的谁" → 引导分身生成。

## 11. 已锁定决策记录

| 决策项 | 选择 | 理由 |
|---|---|---|
| 召回层形态 | 全球每日同题 | 集体悬念比私人事件多硬召回 + 分享钩子 |
| 留存架构 | 双层叠加(召回 + 深度) | 补 v3 前 7 天无硬召回短板 |
| 内容复用 | 一题两用 | 一人扛得住的关键 |
| 后端 | 仅群体聚合计数(Workers+KV) | 集体悬念必要代价,最小后端 |
| MVP 边界 | 召回层 + 深度层最小闭环 | 先验证召回 DAU,再扩深度 |
| 重生层 | Phase 2,数据结构预留 | MVP 不做但为长留存预留 |
| 不来后果 | 软损失(错过机遇不罚) | 粘性与压力平衡 |
| 首发语言 | 中英双语同步 | 全球首发,无障碍传播 |
| 首发朝代 | 唐朝天宝年间 | 史料厚、戏剧性强、海外认知度高 |

## 12. 与 v3 的差异(总结)

v3 押注单一引擎(沉没成本,慢热、重、孤独)。v4 叠加双层引擎:召回层(集体悬念,前 7 天起效、轻、可传播)+ 深度层(v3 沉没成本),共用一套内容库,一人能扛。本质是给 v3 装一个"今天必须来"的硬召回前哨。
