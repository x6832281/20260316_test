# 产品方案文档：你的古代人生 / Your Ancient Life

> **一个让全球用户用 AI 和游戏方式进入中国古代历史的互动平台。**
> An interactive platform that lets global users enter ancient Chinese history through AI and gamification.

---

## 一、产品定位

### 一句话定位
**你有一个古代分身，活在真实的中国历史里。每天一件命运抉择，AI 知己为你参谋，你的每一个决定都不可逆。活完一段人生，再开下一段——唐朝、宋朝、明朝，每一段都是你独一无二的历史。**

英文：
**You have an ancient alter ego living inside real Chinese history. Every day brings one fateful choice. Your AI confidant advises you, but the decision is yours — and irreversible. Live one life, then begin another: Tang, Song, Ming. Each life is a history only you can claim.**

### 核心定位原则（来自 project_rules）
- 不是"讲历史"的内容站，而是让用户"活历史"。
- 把中国历史从"内容"变成"体验"。
- 面向国内与海外双市场，中英双语优先。
- 内容是中国古代历史，产品形态是全球化的。

---

## 二、为什么做这个（市场判断）

### 对标与差异化
对标 **Character.AI**，但走相反路线：

| 维度 | Character.AI | 本产品 |
|------|--------------|--------|
| 核心关系 | 和名人闲聊（浅、多） | 一个深度分身 + AI 知己（深、唯一） |
| 留存引擎 | 角色新鲜感 | 命运推进 + 不可逆 + 沉没成本 |
| 用户动机 | 娱乐、角色扮演 | 被理解、被指引、舍不得走 |
| 文化资产 | 无 | 真实中国历史 + 易经 + 东方美学 |
| 不来的后果 | 无 | 错过机遇（软损失） |

### 趋势红利
- AI 长期记忆成熟 → "懂你的知己"第一次成为可能
- 孤独经济爆发 → "被理解"是顶级需求
- 古风出海红利 → 东方美学全球好奇
- Cozy game / 放置游戏增长 → 慢节奏沉浸被接受
- 海外对中国历史好奇但门槛高 → "穿越活一遍"是空白市场

## 三、三大核心特色（支柱）

### 特色一：真实历史为骨骼，不是皮肤
> 历史不是背景板，是机制本身。换掉历史，产品就不成立。

- **时间线骨骼**：分身出生绑定真实纪年（如开元二十三年洛阳→20 岁撞安史之乱），朝代兴衰直接改写命运
- **史实决策题**：每日事件来自史实两难（幽州商人邀你合伙=安禄山老巢；熙宁党争站队；建炎南渡去留）
- **真实人物网**：同代人是李白、苏轼、王阳明——在汴京瓦子遇见李清照，黄州偶遇被贬的苏轼
- **知识门槛护城河**：懂历史=玩得更好（知道安禄山要反就不去幽州），学习是玩法的副产品
- **朝代化文化沉浸**：衣冠、饮食、婚俗、节气、文风都精确到朝代

### 特色二：AI 知己为导师，决策权在你
> 不是闲聊角色，是陪你活过几段人生的人。

- 唯一型知己：每位用户一位终身知己，长期记忆，越用越懂你
- 5 种 archetype：隐士（道）/ 太史（儒）/ 词客（文）/ 谋臣（智）/ 禅师（佛）
- 遇事给建议（"听闻安禄山举止可疑，宜避"），但最终决策权在用户
- 知己随分身老去，分身故去，知己手札留给下一段人生
- 关系成长：初识 → 相知 → 知己 → 挚交 → 忘年（靠真实互动积累，不靠氪金）

### 特色三：不可逆多周目，沉淀人生卷轴
> 玩上瘾不是因为爽，是因为舍不得那段已经活过的人生。

- 时间推进：1 现实日 = 1 古代月，分身人生按真实日历走
- 软损失：不决策不惩罚，但错过限时机遇（如"安禄山招你，三日未复，已另觅他人"）
- 不可逆：决策不能撤回，AI 推演后续 3-6 月命运
- 人生卷轴：每段人生沉淀成永久资产，可导出成书
- 多周目：分身老死 → 开新人生（换朝代/出身），无限内容

## 四、硬粘性设计（解决"不来没后果"的根本问题）

### 粘性的四种硬力量与对应机制

| 硬粘性 | 机制 | 说明 |
|--------|------|------|
| 悬念 | 每日事件 | 今天他遇到什么？（必须每天看一次） |
| 软损失 | 错过机遇 | 不来不惩罚，但错过限时机遇 |
| 不可逆 | 决策不撤回 | 决策慎重，AI 推演后果 |
| 沉没成本 | 人生卷轴 | 越玩越舍不得断 |
| 重玩 | 多周目 | 想换个朝代出身重来 |

### 每日 3 分钟核心循环
```
上线 → 知己提示今日遇何事（1 min）
  → 起一卦看预兆（1 min，后期加）
  → 决策（1 min）
  → AI 推演 → 分身日记更新 → 人生卷轴延展
  →（可选）看市井里别人在此岔路口的选择 → 关闭
```

## 五、五层历史结合方式（文化核心）

| 层级 | 作用 | 例子 |
|------|------|------|
| 时间线 | 骨骼 | 735 生 → 755 撞安史之乱，月份对应真实历史 |
| 决策题 | 肌肉 | 熙宁党争站队、建炎南渡去留 |
| 人物网 | 血脉 | 拜师吴道子、同榜苏轼、黄州偶遇被贬苏东坡 |
| 知识门槛 | 护城河 | 懂历史=玩得好，错答有史实注脚 |
| 文化沉浸 | 皮肤 | 朝代化衣冠/饮食/婚俗/文风 |

### 历史正确性保障
- 维护**事件时间线库**（朝代/年份/事件/人物的 JSON）
- AI 生成剧情时强约束"必须符合 X 年历史背景，不得虚构重大史实"
- 大事件库做一次，复用 forever（安史之乱、王安石变法、崖山之变…）

## 六、功能模块全景

### MVP 范围（先跑通核心循环）
1. **分身生成**：绑定真实唐朝纪年（开元-天宝年间）
2. **每日事件**：来自天宝年间史实
3. **决策 + AI 推演**：命运后果
4. **分身日记更新**：AI 生成分身视角的日记
5. **中英双语**

### 完整模块（核心循环验证后逐步加入）

| 模块 | 定位 | 优先级 |
|------|------|--------|
| AI 知己 | 分身导师，遇事参谋，长期记忆 | P1 |
| 每日一卦 | 今日事件预兆，结合卦象与日记情绪 | P1 |
| 人生卷轴 | 永久资产，可导出 | P1 |
| 多周目 | 分身老死→开新人生 | P1 |
| 长安城 living map | 人生模拟的舞台呈现（城/街坊/西市） | P2 |
| 匿名市井 | 古今对照——别人在此岔路口怎么选 | P2 |
| 单人悬疑卷 | AI 扮所有角色探案（玄武门/雍正继位等大案） | P2 |
| 节气节日系统 | 24 节气+传统节日特别内容 | P2 |
| 关系成长系统 | 初识→忘年五阶段 | P2 |
| 知己主动惦记 | 基于日记历史的克制 push | P2 |
| 知己语音 | 古风音色 TTS | P3 |
| 人生之书导出 | AI 整理成 PDF/印刷 | P3 |
| 前世测试钩子 | 获客入口"你的前世是哪个朝代的谁" | P3 |

### 模块间的收编关系
- **长安城 living map** → 不是独立产品，是人生模拟的"舞台呈现"。MVP 先用文字跑通，后期加可视化城。
- **AI 剧本杀** → 不做 5 人同步（一人扛不住 moderation + 匹配），改造为"单人悬疑卷"：AI 扮所有角色，作为人生里的重大事件高潮。

## 七、面向全球的设计

1. **知己 archetype 全球通用**：隐士/谋臣/词客/禅师/太史——跨文化的 sage/mentor 概念
2. **易经包装为 wisdom oracle**：不强调算命，强调"3000 年的决策智慧"
3. **文案双语预留**：中文古雅、英文 literary（不用 thou/thee 俗套古英语）
4. **视觉东方但不堆砌**：留白、水墨、灯笼、卦象，极简风，避免"中国城审美"
5. **隐私优先**：日记默认私密，匿名分享可选

## 八、技术方案

### 技术栈（一人能扛）
- **前端**：Vite + Vue 3 + TypeScript + Tailwind CSS
- **国际化**：vue-i18n（中英双语结构）
- **AI 对话**：OpenAI / Claude API（初期），后期可换国内模型降成本
- **数据存储**：LocalStorage / IndexedDB（个人人生数据本地化）
- **部署**：Vercel / Cloudflare Pages（免费额度够用）
- **分析**：Google Analytics + Plausible
- **支付**：Stripe（全球支付）
- **TTS（可选）**：ElevenLabs / 火山引擎

### 关键约束
- 无 UGC 审核（剧情 AI 生成，规避 moderation 成本）
- 无多人同步（每人独立人生，纯单人 + 定时任务）
- 事件库做一次，AI 无限组合
- 纯文字 MVP 成立，TTS/图像后补

### 一人扛得住的关键
- 史实库 JSON + AI 约束生成 = 内容可无限扩展
- 无 UGC = 无审核地狱
- 无多人 = 无匹配/同步/掉线问题
- 本地存储 = 无后端运维

## 十二、已锁定决策记录

| 决策项 | 选择 | 理由 |
|--------|------|------|
| 知己形态 | 唯一型 | 深度羁绊，不可替代 |

| MVP 起点 | 先跑通核心循环 | 验证命门再扩展 |
